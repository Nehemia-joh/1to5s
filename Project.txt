DAILY 1-5S — PRODUCT SPEC
As of: 2026-09-16

===================================================================
1. OVERVIEW
===================================================================
Daily 1-5s replaces the daily standup with a two-minute async form.
Each working day, every person on the roster answers one form: up
to three things they're doing today (at least one required), a
blocker, and a comment on yesterday's work. An admin manages the
roster, holidays, and cutoff times, and reviews everyone's history,
logs, and summaries from one place.

The current build covers login, the core form, and most of the
admin roster/holiday setup end to end. The remaining gaps are
concentrated in richer admin views (trends, graphs, a monthly
rollup) and a few form details (date picker, Excel roster import,
configurable cutoff/close behavior).

3. ROLES & FLOW
===================================================================
  Users  --Adds-->  "Adds 1-5s" (one form per person, per day)
  Admin  --Do-->     "Adds 1-5s"
  Admin  --Do-->     Admin capabilities
  "Adds 1-5s" --Do--> Person filling a 1-5
  "Adds 1-5s" --Do--> The 1-5 form itself

Two roles: Users fill in one 1-5 per working day; Admin configures
the roster, holidays, and cutoff, and consumes the results (views,
logs, summaries).
